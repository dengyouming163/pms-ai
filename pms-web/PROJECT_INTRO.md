# 民宿·AIPMS — 项目介绍

## 一、立项背景与目标

中国民宿数量突破40万家，但多数仍停留在"手工记账+微信群接单"的原始阶段。经营者面临多平台接单混乱、定价凭经验导致收益流失、客户运营粗放复购率低、渠道对账困难、人员权限不清等痛点。传统酒店PMS臃肿昂贵，与民宿轻资产快迭代特征不匹配。

**民宿·AIPMS**定位"AI驱动的民宿智能管理平台"：一站式管理全链路、AI深度赋能转化决策力、多渠道直连告别多系统切换、轻量易用零学习成本、数据驱动经营。

## 二、核心功能模块

### 基础经营模块

**工作台**：经营者的数字驾驶舱，一屏呈现今日营收、入住率、在住间夜等KPI，收入趋势图、待办事项（渠道待确认订单、今日退房、对账异常），内嵌AI定价速览卡片。

**门店管理**：多品牌多门店集团化运营，品牌/门店/房型/房间/设备五级配置。

**房态管理**：日房态矩阵视图，颜色编码区分空闲/入住/维修/锁定，一键入住/退房/换房/锁房/标记清洁；月房态按月展示入住率。

**订单管理**：全渠道订单统一收口，状态/渠道/关键词筛选，待处理订单一键批量确认，支持新建订单和CSV导出。

**价格管理**：价格日历批量调价，基础/周末/节假日价灵活配置，限时特价支持早鸟/连住/折扣。

**渠道管理**：OTA渠道绑定，房态价格双向同步，库存分配，评价聚合管理。

**财务中心**：收支总览含构成饼图，流水逐笔可查，渠道对账自动匹配差异预警。

**客户管理**：客户画像含历史订单/消费/频次，标签分组，关怀提醒，自动规则（如3次入住自动标VIP）。

**团队管理**：员工增删改，角色权限细粒度控制，写操作自动记录日志不可篡改。

### AI核心模块 ★

**AI智能助手**：基于大语言模型SSE流式对话，自然语言提问如"本月哪天入住率最低"，实时调取数据生成回答，多轮对话深入分析。

**AI收益助手**：经营数据智能诊断，自动识别入住率低谷和收益流失点，趋势异常预警，给出可执行改善建议。

**AI智能定价** ★★：核心差异化功能。基于入住率趋势、竞品均价、节假日因素自动生成调价建议，显示当前价→建议价、置信度、竞品均价；一键采纳后自动更新房价并同步渠道；定价日历展示效果，历史可查；AI持续监测动态生成新建议。

## 三、业务流程与功能路径

**日常运营主流程**：登录→工作台查看KPI→待办提醒处理（渠道订单确认→房态更新；今日退房→标记待清洁→净房）→AI定价建议→采纳/忽略→价格自动同步渠道。

**预订→入住→退房全流程**：OTA下单/手动新建→订单确认→房态预占→客人到店办理入住→客人离店办理退房→保洁标记净房→房间重新可售。

**AI智能定价流程** ★：系统自动采集各房型价格、入住率趋势、竞品均价、节假日因素→AI模型分析生成定价建议→经营者查看建议列表→采纳（自动更新房价+同步渠道）或忽略（归档）→持续监测→生成新一轮建议。

**多渠道同步流程**：本系统修改房价/房态→渠道直连自动推送OTA→OTA产生新订单回调至本系统→自动创建订单+房态预占→经营者确认。

**AI功能路径**：AI助手Tab→输入自然语言→SSE流式返回分析结果→可追问；AI定价Tab→查看待采纳建议（房型/当前价/建议价/置信度/原因）→采纳/忽略→查看定价日历和历史；AI收益助手Tab→查看经营数据总览→AI异常识别→改善建议。
